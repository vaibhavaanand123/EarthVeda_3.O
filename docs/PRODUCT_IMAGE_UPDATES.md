# Product image updates

The built-in image-generation edit tool was used for three existing Plant Protein photographs. The selected outputs were inspected, copied into this project and optimized to WebP for the frontend. No external image-generation API key was required.

Final project assets:

- `public/images/protein-mango-clean.webp`
- `public/images/protein-chocolate-clean.webp`
- `public/images/protein-royal-cream-clean.webp`

The corresponding original public image paths also contain the updated label visuals, so the old terminology is not served through those URLs.

Edit prompt used for each flavour:

> Edit the existing EarthVeda Essentials product jar photograph. Preserve the jar, cap, brand, flavour, illustration, lighting, background and framing. Remove the obsolete product term everywhere, including the central small line and round stamp. Replace the central drink name with Plant Protein. Replace the stamp's upper wording with EARTHVEDA and its lower wording with PLANT PROTEIN, keeping the leaf icon. Do not add ingredients, certification, nutritional facts or prices.

These are edited visual assets for the preview. They are not a regulatory approval of the packaging text, product composition, nutritional claims or physical package artwork. The business must approve final label imagery before real sales.
